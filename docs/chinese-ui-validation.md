# 中文菜单与提示验证

版本：v0.1.0-preview.8，2026-10-07。

安装入口、新安装及只读接入向导、参数帮助、程序生成的错误与预检证据、网页菜单与状态、审计记录、反代模板说明改为中文。角色、服务运行方式、Nginx 配置类型支持编号，原英文输入兼容。机器接口、命令参数、配置字段及协议名称保持原标识；系统或官方 FRP 返回的原始诊断可能仍含英文。

验证范围：

- Go 单元与集成测试、go vet；入口与附件同步共 27 项测试通过。
- Linux 编号接入测试通过，既有英文输入测试继续通过；Linux amd64/arm64 编译通过，arm64 未进行实机验证。
- Linux amd64 真实终端执行一键入口，新装两端与只读接入均通过；Token 不回显、取消无安装、实际客户端认证正常、管理程序退出后隧道继续运行。
- 已有部署接入验证定时采集、低权限网页、相同计划重试、源配置变化拒绝执行、新增服务故障清理；测试原服务 PID 和配置摘要保持一致。
- 独立浏览器 fixture 检查登录、菜单、服务端中文字段、审计及 Nginx 模板预览；前端类型检查和打包通过。

以上均为本机及隔离 Linux fixture 验证，未修改生产云服务器、PVE 容器或反代服务。发布附件验收另以实际版本、清单与下载结果为准。
