# 基础阶段验证记录

日期：2026-10-07。范围：本机 Windows、WSL Ubuntu-24.04 的隔离文件与临时测试服务。没有连接生产设备。

## 已验证

- Vue/TypeScript 类型检查与 Vite 生产构建通过，前端嵌入 Go 程序。
- Go 19 项常规测试在 Windows amd64 与 WSL/Linux amd64 通过；`go vet ./...` 通过。
- 官方 FRP 0.71.0 的 Windows/Linux 下载包按 GitHub 官方 Release 资产 SHA-256 验证。
- 集成测试实际调用官方 `frpc verify`；浏览器服务端候选实际调用官方 `frps verify`。均未启动隧道。
- 凭据脱敏、占位符滥用拒绝、未知字段及注释保留、修订冲突拒绝、取消不落盘、幂等保存、加密备份及恢复通过。
- 替换目标二进制后旧计划被拒绝；系统锁互斥与释放通过。
- 启动恢复的测试模拟操作记录处于写入阶段，核对文件后标记状态，不盲目重放。不是整机断电测试。
- 浏览器在一次性 `browserqa` fixture 中实测登录、客户端启用预览/取消/保存、备份恢复、HTTP 代理新增校验及保存、服务端候选校验并取消、systemd 计划生成、WebSocket Nginx 模板生成。
- 测试 fixture 使用独立临时目录与合成账户，完成后测试正常退出并清理临时数据；没有初始化用户预览的管理员。
- Linux amd64 与 arm64 构建通过。amd64 程序与测试在 WSL 实际运行；arm64 仅交叉编译，没有目标硬件运行验收。
- 本任务源码及产物差异检查通过；没有暂存、提交或推送。

没有测试实际 frpc/frps 进程健康、两端认证、代理注册、后端服务或外部业务；没有启动或控制 FRP。没有执行 systemd/Compose 安装、PVE LXC 配置、Nginx 校验/加载、INI 迁移、正式升级/卸载或任何生产变更。
